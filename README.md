# Chatik — оверлей чата Twitch

Показывает чат Twitch поверх всех окон и **не попадает в захват экрана**: зрители на трансляции его не видят.

![PowerShell](https://img.shields.io/badge/PowerShell-5.1-5391FE)

## Возможности

- всегда поверх окон, без рамки и без кнопки на панели задач;
- не виден в OBS (захват окна, игры, экрана), записях и скриншотах;
- чат читается анонимно, без авторизации Twitch;
- копирование сообщений: клик по сообщению + `Ctrl+C` или правая кнопка → «Копировать»;
- настройки: канал, размер окна, шрифт, прозрачность, цвета фона и текста, «поверх всех окон»;
- иконка в трее: скрыть/показать чат, настройки, выход;
- позиция и размер окна запоминаются.

## Требования

- Windows 10 версии 2004+ или Windows 11 (нужно для исключения окна из захвата);
- PowerShell 5.1 — уже есть в Windows, ничего устанавливать не нужно.

## Запуск

1. Дважды кликни `start.vbs` — программа запустится в фоне, без окна консоли и без кнопки на панели задач.
   (`start.bat` делает то же самое, но при запуске может на мгновение мигнуть чёрное окно.)
2. При первом запуске откроется окно настроек — впиши название канала Twitch (можно вставить ссылку `https://twitch.tv/имя`) и нажми «Сохранить».
3. Готово. Оверлей висит поверх окон, чат подключается сам. Управление — через иконку в трее.

## Управление

- **Иконка в трее** — двойной клик: скрыть/показать чат. Правая кнопка: скрыть/показать, «Настройки», «Выход».
- **Перетащить** — потянуть за шапку с названием канала.
- **Изменить размер** — потянуть за уголок в правом нижнем углу.
- **Копировать сообщение** — клик по сообщению выделяет его, дальше `Ctrl+C`; или выдели мышью часть текста. Правая кнопка по чату → «Копировать» (копирует выделение или сообщение под курсором).
- **Правая кнопка мыши по чату** — меню: «Копировать», «Выделить всё», «Очистить чат», «Настройки», «Скрыть в трей», «Выход».
- **Esc** в настройках — закрыть настройки.

## Настройки

- канал Twitch;
- ширина и высота окна;
- размер шрифта;
- прозрачность фона (текст всегда чёткий);
- цвет фона и цвет текста (поле HEX или клик по цветному квадрату — палитра);
- «поверх всех окон».

Всё сохраняется в `config.json` рядом со скриптом, позиция окна — тоже. Журнал ошибок — `error.log`.
Эти два файла в репозиторий не попадают (см. `.gitignore`).

## Про невидимость на стриме

Окно помечается через Win32 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`, поэтому его не видно
ни в OBS (захват окна, игры, экрана), ни в других программах записи и скриншотах.
Это работает только на Windows 10 2004+ / Windows 11. На старых версиях окно будет видно в захвате.

Это касается именно захвата: на мониторе стримера оверлей виден как обычно.

## Автозапуск (по желанию)

Положи ярлык на `start.vbs` в папку автозагрузки: `Win+R` → `shell:startup`.

## Если PowerShell блокирует запуск

Открой PowerShell и выполни:

```
powershell -NoProfile -STA -ExecutionPolicy Bypass -File "путь\chatik\chatik.ps1"
```

Чат читается анонимно (только чтение) — авторизация Twitch не нужна, писать в чат программа не умеет.
